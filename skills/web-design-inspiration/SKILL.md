# Web design inspiration sources

Curated reference sites for AI-assisted web design. Gather 3-5 real references before drafting options, and note which reference inspired each option.

## Sources and what each is for
1. studio.motionsites.ai - describe a business, get an AI-customised MotionSites design with images/video. Quick concept starters.
2. motionsites.ai - 800+ premium website prompts (3D sites, motion sections) to paste into Claude/Cursor. Hero and motion-section ideas.
3. land-book.com - curated landing page gallery, updated daily. Overall page structure.
4. recent.design - web design inspiration gallery. Fresh visual styles.
5. landdding.com - top-quality landing pages. Section patterns (pricing, features, CTA).
6. fontinlogo.com - fonts behind well-known brands. Picking or matching typefaces.
7. godly.website - award-level websites. Ambitious, distinctive directions.
8. 60fps.design - mobile UI animations. Micro-interactions and mobile motion.

Also useful: Mobbin (real app screens and flows) and shadcn/ui (components).

## Steps
1. Confirm goal, audience, brand colours, tone, and content first.
2. Pick the 2-3 sources that fit (structure: Land-book/Landdding; style: Recent/Godly; type: Fontinlogo; motion: MotionSites/60fps; app UI: Mobbin).
3. Collect 3-5 references with URLs and what to borrow (layout, type, colour, motion).
4. Filter against the user's taste and accessibility. Never copy a site wholesale or reuse its assets or copy.
5. Draft 2-3 options naming their references; get approval before finalising.
6. Do an anti-slop polish pass before handoff.
